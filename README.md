# Sudoku（数独アプリ）

C# Windowsフォームで作成したシンプルな数独アプリです。  
9×9 のマスに数字を入力し、数独パズルを楽しむことができます。

---

## 📌 主な機能
- 数字入力（1〜9）
- 入力チェック（同じ行・列・ブロックの重複を防止）
- リセット機能
- シンプルで見やすい UI

---

## 🖥 動作環境
- Windows 10 / 11
- .NET Framework（または .NET 6 以降）  
※プロジェクトのバージョンに合わせて調整してください

---

## 📦 ファイル構成
- `Sudoku.zip`  
　プロジェクト一式が入っています。解凍して Visual Studio で開いてください。

---

## 🚀 使い方
1. リポジトリをクローンまたは ZIP をダウンロード  
2. Visual Studio でプロジェクトを開く  
3. 実行ボタン ▶ を押して起動  
4. 数字を入力してプレイできます
