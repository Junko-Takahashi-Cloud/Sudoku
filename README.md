# 🧩 Sudoku（数独アプリ）– C# / Windows Forms

このアプリは、C#（Windows Forms）学習の一環として  
**「UI操作」「イベント処理」「ロジック実装」** を目的に作成した数独ゲームです。

---

## 🎮 概要
9×9 の数独パズルを解くための  
**シンプルで分かりやすい Windows アプリ** です。

- マスをクリックして数字を入力  
- 入力チェック  
- リセット機能  
- 初期問題の表示  

---

## 🛠 使用技術
- C#  
- .NET  
- Windows Forms  
- Visual Studio  

---

## ✨ 機能一覧
- 数字入力（1〜9）  
- 入力エラーの簡易チェック  
- 盤面のリセット  
- 初期問題の読み込み  

---

## 💡 工夫した点
- Windows Forms の基本操作（イベント処理・コントロール配置）を意識  
- 初心者でも扱いやすい UI  
- コードを読みやすくするためのメソッド分割  
- “動くものを作る” を最優先に設計
